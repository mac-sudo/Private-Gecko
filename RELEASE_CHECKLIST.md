# Проверки 0.9.0-beta.1

Статус подготовки на 3 ноября 2026. Галочки отражают наблюдавшиеся результаты,
а не гарантию отсутствия ошибок.

## Выполнено в проекте

- [x] Сохранены applicationId, профиль, разрешения и настройки декодирования.
- [x] Добавлены настройки блокировки, очистки фото, уведомлений и локальные документы.
- [x] Нейтральное имя и новый собственный векторный значок.
- [x] Gradle Wrapper 9.8.0; SHA-256 дистрибутива и wrapper JAR сверены с services.gradle.org.
- [x] Инвентаризация 53 runtime-артефактов с SHA-256 и лицензиями из POM.
- [x] Точная ревизия Gecko и встроенные upstream-уведомления.
- [x] CI без релизных ключей, статические проверки APK, безопасный архив исходников.

## Проверки текущей сборки

Результаты сборки, подписи, телефона и чистой распакованной копии записаны
в RELEASE_VALIDATION.md. Пять оставшихся предупреждений lint разобраны отдельно.
Владелец подтвердил нормальную работу после обновления.

## Публикация beta и дальнейшая стабилизация

- [x] Указан реальный адрес репозитория и закрытого канала сообщений об уязвимостях.
- [ ] Офлайн-бэкап ключей с проверкой восстановления (действие владельца).
- [ ] Реальные прогоны на нескольких моделях/производителях и версиях Android.
- [ ] Сценарии на тестовом аккаунте: новый вход, первое открытие MP4/WebM, файлы,
      отмены/ошибки, offline/reconnect, фон, уведомления, системная блокировка, очистка.
- [ ] Разобрать прежний симптом открытия видео со второго раза, если воспроизводится.
- [ ] Назначить сопровождающего security-обновлений и определить поддержку beta.
- [ ] Проверка публикации исходников/лицензий и release notes владельцем.

Beta публикуется с явно указанными ограничениями. Незавершённые проверки других
устройств не считаются пройденными и нужны до объявления стабильной 1.0.0.

Пока проверена одна модель realme RMX5210 / Android 16 / arm64.
Android 9–15 и другие производители не считаются проверенными.
Публичная политика описывает, что сетевые назначения Gecko и авторизованный трафик
не были полностью исследованы; «нулевую телеметрию» заявлять нельзя.
