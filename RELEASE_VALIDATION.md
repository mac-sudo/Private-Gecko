# Проверка сборки 0.9.0-beta.1 — 3 ноября 2026

## Итог

Комплект beta подготовлен для https://github.com/mac-sudo/Private-Gecko.
Обновление рабочей установки с 0.2.8-private на 0.9.0-beta.1 принято Android
без удаления пакета; versionCode=3, дата первой установки сохранилась.
Владелец подтвердил нормальную работу после обновления; содержимое аккаунта
в ходе инженерной проверки не читалось.

## Проверки

- Gradle Wrapper 9.8.0 действительно загрузил дистрибутив и собрал проект.
  SHA-256 дистрибутива проверен Wrapper; JAR сверён с services.gradle.org.
- 11 unit-тестов: 0 failures, 0 errors.
- Lint: 0 ошибок, 5 предупреждений; глобального подавления предупреждений нет.
- Статическая проверка release APK прошла: package/version, разрешения, экспорт
  компонентов, backup/cleartext, отсутствие тестовых медиа и verification-класса,
  наличие документов и ограничивающих prefs, V3 и закреплённый сертификат.
- Подпись: RSA-3072; сертификат SHA-256
  ce2879796a3b5c7063017527eef815b89c9c2cfff3187b33f418449616f46f31.
- SHA-256 локального кандидата, проверенного на телефоне:
  2c2bc115c0f4a792541eb63fe68279e02fb9d3886932cff6cf679c4497c6802b.
  Перед публикацией обновлены только документы и ссылки на репозиторий. Исполняемые
  DEX, ресурсы и native-библиотеки сверяются с этим кандидатом; хеш финального APK
  отличается и указан в SHA256SUMS выпуска. Переустановка на телефон для изменения
  ссылок не требуется; его подключение для публикации не нужно.
- Архив исходников распакован в отдельную папку без local.properties, ключей и
  старых build-каталогов. Сборка с ANDROID_HOME и dependency-verification strict прошла.
  Использован тот же компьютер и кеш зависимостей: независимая чистая машина не заявляется.
- Содержимое всех ZIP-записей unsigned APK из проекта и распакованных исходников
  совпало побайтно. Полные SHA-256 ZIP отличаются из-за упаковки; побитовая
  воспроизводимость всего APK не заявляется.
- GitHub Actions workflow подготовлен, но ещё не запускался на GitHub.

## Телефон

realme RMX5210, Android 16, arm64. Проверка в отдельном временном пакете без аккаунта.
Итог текущей verification-сборки наблюдался на экране:

Защиты=true; H264=true; MP4/WebM=1:1; OK/OK; фото=true; очистка=true

MP4/WebM воспроизводились до ended; проверены синтетическое фото с EXIF/GPS,
очистка собственных тестовых файлов и повторная самопроверка после очистки.
Переключатели блокировки и очистки фото менялись, сохранялись после закрытия
и повторного открытия настроек, затем возвращены в исходное состояние
только в тестовом пакете. Политика приватности и лицензии Gecko открывались
в нативном интерфейсе без браузерного выполнения. Пользовательские настройки
рабочего пакета не переключались.

После проверки временный пакет удалён; на телефоне оставлено рабочее приложение.
Другие модели и Android 9–15 не проверены. Сценарии реальной переписки, входа,
первого открытия видео и уведомлений после обновления требуют проверки владельцем.

## Оставшиеся предупреждения lint и решения

| Предупреждение | Решение |
|---|---|
| ScopedStorage | Относится к tools:node=remove для READ_EXTERNAL_STORAGE. В финальном APK разрешения нет; маркер сохраняется против транзитивного добавления. |
| OldTargetApi | targetSdk 36 сохранён ради проверенного Android 16. Переход на 37 требует отдельной проверки новых ограничений, не сделан формально ради отсутствия предупреждения. |
| UnusedAttribute | allowAudioPlaybackCapture=false действует с API 29; на API 28 такой механизм системного захвата не поддерживается. Защита сохранена для поддерживающих API. |
| AndroidGradlePluginVersion | Закреплён и проверен Gradle 9.8.0; lint сообщает о 9.8.2. Обновление инструментов проверяется отдельно, срочная уязвимость этим предупреждением не установлена. |
| ChromeOsAbiSupport | Только arm64 заявлен явно; поддержка x86_64/ChromeOS не обещается. |

Дополнительно компилятор отмечает deprecated API системной проверки credentials,
а чистая сборка сообщала об аннотациях upstream и невозможности повторно strip
часть готовых библиотек Gecko. Сборка успешна; native-библиотеки не модифицировались.

## Что невозможно закрыть одной локальной сборкой

- Несколько физических моделей/производителей и версии Android.
- Полное исследование всех фоновых соединений и независимый пентест.
- Восстановление ключей из зашифрованной офлайн-копии: права локального каталога
  и файлов проверены (700/600), но резервный носитель владелец ещё не предоставлял.
- Назначение сопровождающего и гарантий поддержки. Репозиторий и закрытый канал
  указаны реальными ссылками; гарантированный SLA не объявлен.
