# Обновления и версия

Private Gecko 0.9.0-beta.1 — предварительный выпуск неофициальной оболочки MAX Web.
Проверенная платформа: realme RMX5210, Android 16, arm64; результаты новой сборки
указаны в RELEASE_CHECKLIST.md. Android 9+ заявлен конфигурацией сборки, но
полная совместимость со всеми устройствами пока не подтверждена.

Репозиторий проекта: https://github.com/mac-sudo/Private-Gecko
Обновления: https://github.com/mac-sudo/Private-Gecko/releases
Обновляйте только из Releases этого репозитория.
Сверяйте SHA-256 APK с файлом SHA256SUMS того же выпуска и сертификат подписи:
ce2879796a3b5c7063017527eef815b89c9c2cfff3187b33f418449616f46f31

Android дополнительно проверяет совместимость подписи при установке поверх.
Один хеш с того же скомпрометированного сайта не доказывает подлинность.
Не удаляйте предыдущую версию перед обновлением: вход и данные пропадут.
Оболочка не устанавливает обновления самостоятельно и не запрашивает
разрешение установки других приложений.

GeckoView требует обновления самого APK: обновление Android System WebView
его не заменяет. Владелец выпуска проверяет бюллетени Mozilla перед релизом
и при сообщении о срочной уязвимости. Гарантированный срок поддержки beta
пока не установлен; для стабильной 1.0 он должен быть определён.
