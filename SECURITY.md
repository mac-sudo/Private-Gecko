# Безопасность и сопровождение

## Сообщить об уязвимости

Используйте GitHub Private vulnerability reporting:
https://github.com/mac-sudo/Private-Gecko/security/advisories/new
Не отправляйте чувствительную уязвимость, переписку или токены в публичный Issue.
Гарантированного SLA beta пока нет; поддержка стабильной 1.0 ещё не объявлена.

## Обновления

Владелец проверяет бюллетени Mozilla перед каждым выпуском и при срочных уведомлениях.
`node scripts/check-engine-updates.mjs` сравнивает закреплённый движок с Maven release.
Этот скрипт работает на компьютере, не в приложении; не собирает данные аккаунта
и не устанавливает обновления. Обновлять движок нужно новым APK.
Технический CI не заменяет ответственность сопровождающего за срочный выпуск.

Проверяйте отдельную verification-сборку, реальные видео, обновление без потери входа,
разрешения APK, подпись и документацию. Не отключайте изоляцию ради видео.
Не включайте удалённую отладку, глобальный CA, VPN-перехват аккаунта или расширенный MOZ_LOG.

## Ключи

Ключ релиза должен храниться вне репозитория, в каталоге владельца с правами 700,
ключ и password-file — 600. Используется V3-ротация с прежнего локального debug-сертификата,
rollback старому подписанту не разрешён. Не публикуйте ни текущий, ни старый debug-ключ,
password-file или lineage. Ключи в GitHub CI не требуются.

Перед публичным выпуском владелец должен создать и проверить восстановление отдельной
зашифрованной офлайн-копии ключей. Этот проект не создаёт такую копию автоматически
и не утверждает, что она уже существует. Потеря ключа может сделать обновление невозможным.
Хранение ключа и пароля рядом не защищает от компрометации учётной записи компьютера.

## Минимальные логи нативного сбоя

Сначала запишите время, версию, модель и действие без данных переписки.
Не очищайте весь logcat и не собирайте полный bugreport. На своём компьютере:

```sh
adb logcat -b crash -d -t 150 > crash-local.txt
```

Буфер crash может содержать сведения других приложений, пути и идентификаторы.
Просмотрите файл локально, оставьте только относящиеся к Private Gecko строки:
Fatal signal, имя процесса, Cause, адреса/BuildId и стек libxul.so.
Удалите серийные номера, аккаунты, URL, имена вложений и лишние строки.
Не отправляйте сырой файл автоматически; воспроизводите на тестовых файлах.

## Границы

Профиль сохраняется ради входа. Блокировка — интерфейсная проверка Android, не новое
шифрование профиля. Очистка не удаляет данные MAX на сервере и не обещает forensic erase.
Фильтр AppTracer не означает полного отсутствия аналитики. Встроенные сетевые службы
Gecko и авторизованный сетевой трафик полностью не измерены.
RDD использует UID приложения; изоляция content не означает UID-изоляцию всех процессов.
Не заявляйте «полностью безопасно», «анонимно» или «Google-free».
